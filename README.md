# HexSoftwares_Iris_EDA_Analysis
Exploratory Data Analysis of the Iris dataset using Python (Pandas, Matplotlib, Seaborn)

## key Insight
* Setosa has distinctly smaller petals.
* Petal features show 96% correlation.
* Virginica is the largest species.

## How to run
1. Downoload the CSV file into your computer make sure it is save in yur Downloads file.
2. Open the jupyter Notebook 'Iris_EDA.ipynb'.
3. Run all cells
